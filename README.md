# 紫色晶石（Stoneshard）加速器

给单机游戏《紫色晶石 / Stoneshard》用的移动速度加速工具：把游戏的**时间流速**调快，
角色走一格、跑图、动画、AI 回合在现实时间里就快 N 倍，等于角色移动速度变快。

## 怎么用

1. 双击 **`启动加速器.bat`**（无控制台窗口；出问题就用 `启动加速器-控制台.bat` 看报错）。
2. 点「启动游戏」，或者自己从 Steam 启动游戏。工具会**自动注入**（勾了"自动连接"的话）。
3. 拖动倍率滑块，游戏里立刻生效。默认 1.5x，建议 1.5x ~ 2.0x，太快再往下调。
4. **按 F8 开关加速**：关掉就恢复原速，再按一下回到滑块上的倍率。游戏全屏时也管用。
5. 想彻底恢复：点「还原原速」。关掉工具也会自动还原。

倍率含义：`2.0x` = 游戏里的 1 秒相当于现实 0.5 秒，角色走路速度、动画速度都翻倍。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| **F8** | 开启 / 关闭加速（全局有效，游戏窗口在前台时也能按） |

F8 被别的软件占用时会自动改用 F9、F10、F11，界面上会显示实际用的是哪个键。
「关闭」并不是把注入撤掉，只是把时间倍率临时设回 1.0x，所以开关是瞬间生效、可以随便按的。

## 洗点（改存档）

主界面上的 **「洗点 / 改存档」** 按钮会打开洗点窗口，里面列出所有角色的存档、
等级、五项属性和剩余点数。两个功能：

**属性洗点**：把力量/敏捷/感知/体质/意志全部退回下限 **10**，省下来的点数
**全部退回「属性点」（AP）**，总点数一分不多一分不少。回到游戏里打开角色界面，
用那些属性点重新分配就行。

举例：一个 25 级角色是 21/11/25/11/10、属性点剩 0（总共 78 点），洗点后变成
10/10/10/10/10、属性点 28 —— 你可以按自己的新思路重新加 28 点。

**技能点**：直接把未分配的技能点设成你要的数字。注意这**不会退掉已经学会的技能**
（技能树的依赖关系在游戏数据里，光靠存档算不准，所以没做自动退技能）。

用法：**先完全退出游戏**，点「洗点」，选一行存档，点「洗点」按钮；默认会把该角色的
所有存档一起改（因为游戏"继续游戏"读的可能是另一份），也可以勾「只改选中的这一份」。

**安全网**：每次改动前自动把整个存档目录备份到
`%LOCALAPPDATA%\Stoneshard_Backup\时间戳\`，窗口里的「恢复备份…」可以一键还原。
万一游戏不认改过的存档，点它还原就回到原样。

命令行也可以用：

```powershell
python stoneshard_accel.py --respec-list            # 列出所有存档和属性
python stoneshard_accel.py --respec character_3     # 给 character_3 全部存档洗点
python stoneshard_accel.py --respec character_3/save_1   # 只洗指定的一份
python stoneshard_accel.py --respec-sp character_3=5     # 技能点设为 5
python stoneshard_accel.py --respec-backup          # 手动备份
python stoneshard_accel.py --respec-restore 20260919_213000   # 从备份还原
```

存档格式是自己逆出来的：`zlib 压缩（JSON 正文 + 32 位随机 ID + \0）`，正文里
`characterDataMap` 就是角色数据。工具只改动其中几个数字字段，其余内容逐字节不动
（改动前后会做一次完整的结构比对，发现改到别处就自动放弃）。那串 32 位 ID 用各种
哈希算法都验过，和内容无关，原样保留。

## 命令行用法

```powershell
python stoneshard_accel.py              # 图形界面
python stoneshard_accel.py --set 2.5    # 直接设成 2.5 倍
python stoneshard_accel.py --test       # 注入并实测真实加速比例（自检）
python stoneshard_accel.py --restore    # 还原游戏原始速度
python stoneshard_accel.py --selftest   # 不碰游戏，本地验证注入代码是否正确
```

## 原理

* 游戏是 GameMaker 引擎做的，主循环靠 Windows 计时函数（`QueryPerformanceCounter`、
  `timeGetTime`、`GetTickCount64`）来排帧，出招/走路的时长都由这些时钟算出来。
* 工具用 `WriteProcessMemory` 在游戏里放一小段**手写的 x64 机器码**，把游戏主程序导入表
  里的这三个计时函数的地址，换成"时间走得快 N 倍"的替身函数（和 Cheat Engine 的
  Speedhack 一个路子）。
* 替身函数内部仍然调用真正的系统函数拿真实时间，只是把两次调用之间的**增量**乘以倍率再
  累加，所以游戏看到的时间是连续的、单调的，不会跳变；倍率随时可改，改完立即生效。
* 这段机器码是把指令按字节拼出来的（脚本内自带一个小汇编器），**不需要装编译器**。

## 安全性

* 只改游戏进程的内存，**不修改任何游戏文件**，退出游戏即彻底消失。
* 只挂钩 `StoneShard.exe` 自己的导入表，不动系统 DLL，不影响其它程序。
* 「还原」= 把原始函数地址写回去，游戏就完全恢复原状。
* 单机游戏，没有联机对战，不存在影响别人的问题。

## 常见问题

**提示"打开游戏进程失败，错误码 5"**
右键用管理员身份运行，或者确认游戏不是以管理员身份启动的。

**提示"没有找到 StoneShard.exe"**
游戏没启动，或者进程名不同（游戏更新后可能变）。先启动游戏再点「连接游戏」。

**注入成功但感觉没变快**
先用 `--test` 看看实测比例。若比例是 2.0 但体感没变，说明这个游戏版本的主循环没走这三个
计时函数，把结果反馈给我，我换挂钩点（比如 GML 里 `delta_time` 的计算处）。

**游戏更新后失效**
换挂钩点的地址是每次运行时动态解析导入表得到的，一般不受更新影响；真失效了就用
`--test` 把实测结果发我。
